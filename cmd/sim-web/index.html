net-sim   {{.ConfigPath}}

What is this?  click to expand

This is the control surface for an AX.25 packet network simulator. Edit the YAML below to describe a network of nodes, ports and links; click Apply & restart to bring it up. Each port becomes one samoyed-direwolf child process exposing a KISS TCP port your AX.25 application connects to. The router moves audio between ports through an FM capture-effect mixer — no real radios involved.

Workflow

  1. Edit the YAML in the textarea. Strict parser — unknown keys are errors.
  2. Save writes to {{.ConfigPath}} after validation. Doesn't restart anything.
  3. Apply & restart = Save + restart the router with the new config.
  4. Stop tears it all down. The KISS TCP listeners go away.

YAML sketch

mixer_mode: fm_capture
capture_db: 6.0          # FM capture ratio, dB
collision_mode: silence  # silence | sum (stub) | noise (stub)

nodes:
  - id: a
    callsign: SIMA
    ports:
      - id: vhf
        modem: { mode: afsk1200 }
        kiss_port: 8001     # TCP port your AX.25 app connects to

links:                       # directional; both ends must agree on modem
  - { from: a.vhf, to: b.vhf, loss_db: 0, noise_db: 0 }

Hidden-node demo (capture effect)

Three nodes A, B, C; A↔B and B↔C linked, A↔C deliberately missing. Equal loss → A and C transmitting together collide at B. Set A's loss to 3 dB and C's to 15 dB and run again — A "captures" the demodulator at B because its 12 dB margin clears the 6 dB threshold. Try it.
